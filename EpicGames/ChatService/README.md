# Hosts

This are some (not all) Hosts that you can access the Chat Service from

- api.epicgames.dev (`/epic/chat`)

<br/>

Recommended Hosts:

- api.epicgames.dev

All paths are prefixed with `/epic/chat`. Conversation `type` values seen: `dm`, `group`, `epic_party`. Realtime events: `social.chat.v1.*` over [Epic Connect](../../Launcher/Social/Connect.md). Message bodies are signed, see [Signing](../../Launcher/Social/Signing.md).
